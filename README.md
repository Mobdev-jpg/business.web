# ORVEXA DIGITAL

Responsive multi-page website for ORVEXA DIGITAL.

## Pages
- `index.html` — Home
- `services.html` — Services
- `portfolio.html` — Portfolio concepts
- `about.html` — About
- `pricing.html` — Introductory packages
- `contact.html` — Contact and enquiry form

## Assets
- `style.css` — Responsive dark navy and blue visual system
- `script.js` — Mobile navigation and enquiry email preparation

## Run locally
Open `index.html` in a browser. Keep all files in the same folder.

## Before publishing
Replace `your-email@example.com` in `script.js` and `contact.html` with the real business email. Add a WhatsApp number and update pricing as needed. The contact form currently prepares an email; it does not submit to a server.
